# Contributors

DualSub Replay gets better because people share ideas, report bugs, test builds and send code. Thank you, everyone listed here.

You don't need to write code to be listed. If an idea you posted in [Discussions](https://github.com/hoangkien1703/dual-sub-replay/discussions), a bug you reported in [Issues](https://github.com/hoangkien1703/dual-sub-replay/issues) or a build you tested shaped a release, you belong here. The pull request that ships it adds you, and that release's notes thank you by name. If we missed you, say so in a Discussion.

The icons follow the [all-contributors key](https://allcontributors.org/docs/en/emoji-key): 💻 code, 🎨 design, 📖 docs, 🤔 ideas and feedback, 🐛 bug reports, 📓 testing, 🚧 maintenance.
