# DualSub Replay roadmap

This roadmap is directional, not a promise of dates or features.

## Now

- Keep caption discovery, translation, and replay reliable as YouTube changes.
- Improve fullscreen and landscape behavior across more Android devices.
- Strengthen accessibility, error messages, and offline test coverage.

## Next

- Make caption-provider failures easier to diagnose and recover from.
- Improve documentation and community translations.
- Evaluate additional trusted distribution channels while preserving signing continuity.

## Exploring

- More learning-oriented controls without creating a second video player.
- Optional study workflows that remain private and useful offline.
- A replaceable caption-provider boundary if YouTube's internal transcript interface changes.

Suggestions are welcome through the repository's feature-request template. Please search existing issues first.
