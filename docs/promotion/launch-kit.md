## Show HN

### English

Title: Show HN: DualSub Replay – dual YouTube subtitles and tap-to-replay on Android

DualSub Replay is a free, open-source Android app I built for sentence-by-sentence language learning with YouTube. It uses one embedded YouTube webpage player, displays original and on-device translated captions together, and lets a learner tap a subtitle paragraph to seek that same player back to its start.

The project is Kotlin/Jetpack Compose. Translation uses ML Kit without an API key. Caption retrieval is deliberately isolated because it depends on YouTube's undocumented transcript interface. I would especially value feedback about the single-player architecture, caption resilience, and whether the interaction is useful for real study.

https://github.com/hoangkien1703/dual-sub-replay
